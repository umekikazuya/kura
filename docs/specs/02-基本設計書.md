# 02. 基本設計書

## 1. ウィンドウマネジメントとUI仕様

OSのネイティブウィンドウクロムを完全に排除したボーダーレスUI。

- Window Level: `NSMainMenuWindowLevel` + 1 に設定し、他のすべてのフローティングウィンドウ（SpotlightやRaycast等）より確実に最前面に描画する。
- レンダリング最適化: Apple SiliconのUMA (Unified Memory Architecture) を活かし、LitによるDOM更新は必ず `requestAnimationFrame` 内にバッチ処理させ、GPUコンポジティングを強制する。
- 仮想スクロール (Virtual Scrolling): 検索結果が数万件に及ぶ場合でも、DOMノード数は常に画面の可視範囲＋バッファ（最大30ノード程度）に制限し、DOMの爆発によるレンダリング遅延を防ぐ。

## 2. キーバインドとステートマシン

グローバルなキーフックにはMacの `Carbon/HIToolbox` ではなく、最新の `Quartz Event Services (CGEventTap)` を使用し、低レイテンシでキー入力を横取りする。

| アクション           | キーバインド              | 状態遷移 / システム挙動                                                                                                  |
| -------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| トグル起動           | `Cmd + Option + V`        | `Wailsの WindowShow()` 呼び出し + 検索入力への強制フォーカス。                                                           |
| ウィンドウ破棄       | `Esc / Ctrl + C`          | Wailsの WindowHide() 呼び出し + Go側のメモリキャッシュ（検索結果）の破棄。                                               |
| リストナビゲーション | `j / k (または Ctrl+N/P)` | リスト内のアクティブインデックス移動。押しっぱなし時のキーリピートイベントを間引く（Debounce）。                         |
| FTS検索              | 文字入力                  | 入力ごとにGoプロセスへIPC通信。300msのディレイを待たず、入力のたびに即時クエリを発行。                                   |
| ペースト実行         | Enter                     | 選択データを `NSPasteboard` の先頭にセット → ウィンドウ非表示 → 前のアプリへ `cmd + V` の `CGEvent` をエミュレート送信。 |
| 即時物理削除         | `Cmd + Backspace / dd`    | 選択項目をSQLiteおよびインメモリから物理削除し、直ちに画面を再レンダリング。                                             |

## 3. アプリケーション設定

`~/.config/<appname>/config.json` にて管理。
設定ファイルの変更は `fsnotify` によって監視され、アプリの再起動なしにGoのバックエンドへ即時反映される。
