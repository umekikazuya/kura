# 03. 詳細設計書（内部設計書）

## 1. アーキテクチャ構成

Go (バックエンド) と Lit (フロントエンド) を Wails IPCでバインディングする。
Go側でページネーション（先頭50件）を行い、フロントエンドには描画に必要な最小限のDTO (Data Transfer Object) のみを受け渡す。
監視ループには `time.Sleep` を用いず、`CFRunLoop` を用いたイベント駆動（Notification）を採用する。

## 2. データベース物理設計 (SQLite FTS5)

パフォーマンスチューニングのため、以下のPRAGMAを設定し、N-gramを用いた仮想テーブルを構築する。

```sql
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA mmap_size = 268435456;

-- メインテーブル
CREATE TABLE clips (
id TEXT PRIMARY KEY,
content_hash TEXT NOT NULL,
type TEXT NOT NULL,
image_path TEXT,
source_app_bundle_id TEXT,
is_pinned BOOLEAN DEFAULT 0,
created_at INTEGER DEFAULT (cast(strftime('%s','now') as int)),
updated_at INTEGER DEFAULT (cast(strftime('%s','now') as int))
);

-- FTS5仮想テーブル（あいまい検索用）
CREATE VIRTUAL TABLE clips_fts USING fts5(
content,
content_id UNINDEXED,
tokenize='trigram'
);

-- 同期トリガー
CREATE TRIGGER after_clips_insert AFTER INSERT ON clips BEGIN
INSERT INTO clips_fts(content_id, content) VALUES (new.id, new.content);
END;
```

## 3. モジュール・クラス設計

- 監視モジュール: OSの NSPasteboard 変更イベントを検知。機密フラグ (org.nspasteboard.ConcealedType) を評価し、対象外なら破棄。
- データアクセスモジュール: 重複登録時はINSERTではなく updated_at のUPSERTを行い、リストの最上位に移動させるトランザクションを実行する。
