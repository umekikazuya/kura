# 01. ビルド・リリース設計

> kura のビルドパイプライン、macOS アプリ配布方法、および自動更新の仕組みを定義する。

---

## 1. ビルドパイプライン

### 1.1 ターゲット

| 項目           | 値                               |
| :------------- | :------------------------------- |
| アーキテクチャ | Apple Silicon (ARM64) 専用       |
| 最小 OS        | macOS 13 (Ventura)               |
| Intel (x86_64) | **非対応**（Rosetta 2 も保証外） |

### 1.2 ローカルビルド

```bash
# 開発時（ホットリロード）
wails dev

# 本番ビルド（.app バンドル生成）
# ※Wails 内部で自動的に Ad-hoc 署名が付与される
wails build -platform darwin/arm64 -clean

# 出力先
# build/bin/kura.app
```

### 1.3 フロントエンドのビルド

Wails の `wails build` コマンドが自動的に以下を実行する：

```bash
cd frontend && npm install && npm run build
```

フロントエンドのビルド成果物は Go のバイナリに埋め込まれる（`//go:embed`）。

## 2. コード署名と Gatekeeper 対策（OSS要件）

> **要件定義（移行計画書）準拠**:
> 本プロジェクトは OSS として提供するため、有償の Apple Developer Program による証明書署名・公証（Notarization）は**実施しない**。

### 2.1 Ad-hoc 署名

ビルド時に付与される署名は、ローカルで実行可能な最小限の **Ad-hoc 署名**（`codesign -s -`）のみとする。公証を必須とする Hardened Runtime（`--options runtime`）や、厳密な `entitlements.plist` の定義は行わない。

### 2.2 Gatekeeper ブロックの回避手順

公証されていないアプリケーションをインターネット（GitHub Releases）からダウンロードして開く際、macOS の Gatekeeper（Quarantine 属性）によって起動がブロックされる。
これを回避するため、**エンドユーザー向けに以下の解除コマンドの実行をドキュメントで案内する**。

```bash
# インストール（Application フォルダ配置）後の初回起動前に実行
xattr -cr /Applications/kura.app
```

## 3. 配布フォーマット

| フォーマット    | 説明                             | 対象                 |
| :-------------- | :------------------------------- | :------------------- |
| `.dmg`          | ドラッグ＆ドロップインストーラー | 主要配布形式         |
| GitHub Releases | バイナリ直接ダウンロード         | 一般ユーザー・開発者 |

### 3.1 DMG 作成

```bash
# create-dmg ツールを使用
npx create-dmg build/bin/kura.app build/ \
  --overwrite \
  --dmg-title "kura" \
  --window-size 660 400 \
  --app-drop-link 460 170
```

## 5. 自動更新

Wails 標準の自動更新機能（`go-update` ベース）を使用する。

### 5.1 更新チェックフロー

```text
アプリ起動時 / 24時間ごと
       ↓
GitHub Releases API を確認
https://api.github.com/repos/umekikazuya/kura/releases/latest
       ↓
現在のバージョン < 最新バージョン？
├─ NO  → 何もしない
└─ YES → システム通知「kura v<X.Y.Z> が利用可能です」
              ↓（ユーザーがクリック）
         DMG のダウンロード URL を開く（ブラウザ）
```

## 6. ログ・クラッシュレポート

- ログ出力先: `~/Library/Logs/kura/kura.log`
- クラッシュレポート: macOS 標準のクラッシュレポートを使用
- **外部サービスへの送信なし**（ネットワーク通信ゼロポリシーに準拠）
