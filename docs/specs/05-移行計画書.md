# 05.移行計画書（導入・リリース計画）

## 1. ビルド・リリース計画

本システムはOSSとしてGitHub Releases経由でバイナリ（DMGファイル）を提供する。

- ビルド自動化: GitHub Actionsを利用し、タグ発行時に `macos-latest` (M1環境) にてUniversal Binaryをビルドする。
- Apple公証の扱い: 有償のNotarization（公証）は実施せず、Ad-hoc署名のみとする。

## 2. 導入・インストール手順

エンドユーザー向けの導入手順を以下に定める。

1. GitHub Releasesより最新の `.dmg` ファイルをダウンロード。
2. Applicationフォルダへ配置。
3. 未公証アプリによるGatekeeperのブロックを回避するため、初回起動前にターミナルから以下の検疫属性解除コマンドを実行させる。
   `xattr -cr /Applications/Kura.app`

## 3. データ移行・初期化計画

- 初期設定: 初回起動時に、アプリケーションは ~/.config/kura/ ディレクトリおよび ~/.local/share/kura/data.db を自動生成する。
- 権限付与: 初回起動時、OSの「アクセシビリティ権限」の許可をユーザーに要求するダイアログを表示する。
