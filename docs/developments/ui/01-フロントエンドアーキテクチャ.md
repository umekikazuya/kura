# 01. フロントエンドアーキテクチャ・状態管理設計

> kura のフロントエンド（Wails WebView 内で動作する UI）の技術スタック、ディレクトリ構成、状態管理、およびスタイリングの戦略を定義する。

---

## 1. 技術スタック

| 領域                  | 採用技術                | 理由                                                                                     |
| :-------------------- | :---------------------- | :--------------------------------------------------------------------------------------- |
| **UI フレームワーク** | React (TypeScript)      | 豊富なエコシステム、仮想スクロールライブラリの充実、高い生産性。                         |
| **ビルドツール**      | Vite                    | Wails 標準のフロントエンドビルドツールとして統合が容易であり、HMR が極めて高速。         |
| **状態管理**          | Zustand                 | ボイラープレートが少なく、軽量かつ React の再描画を最適化できるため。                    |
| **スタイリング**      | Tailwind CSS            | ユーティリティクラスにより、macOS ライクな UI を高速かつ一貫して構築できる。             |
| **仮想スクロール**    | @tanstack/react-virtual | 仮想スクロールのデファクトスタンダード。DOM ノード数を最小限に抑えパフォーマンスを維持。 |

---

## 2. ディレクトリ構成

クリーンで保守しやすい構造とする。

```text
frontend/src/
├── components/      # UI コンポーネント
│   ├── KuraApp.tsx
│   ├── SearchInput.tsx
│   └── ClipList/
│       ├── ClipList.tsx
│       └── ClipItem.tsx
├── store/           # Zustand ストア定義
│   └── useClipStore.ts
├── hooks/           # カスタムフック (IPC 呼び出しのラップ等)
├── styles/          # Tailwind エントリーポイント・グローバル CSS
└── wailsjs/         # Wails が自動生成する Go バインディングコード
```

## 3. 状態管理設計 (Zustand)

アプリ全体で共有する状態は `useClipStore` に集約し、Props のバケツリレーを排除する。

```typescript
interface ClipState {
  // State
  items: ClipItemDTO[];
  query: string;
  selectedIndex: number;

  // Actions
  setQuery: (query: string) => void;
  setItems: (items: ClipItemDTO[]) => void;
  setSelectedIndex: (index: number) => void;
  moveSelectionUp: () => void;
  moveSelectionDown: () => void;
}
```

- フロントエンド側は「状態を保持するだけ」であり、実際の検索や削除の副作用（副作用の解決）は Go 側の IPC メソッド (`SearchClips`, `DeleteItem` 等) を呼び出す。
- IPC イベント（`clip:created` 等）を Go からプッシュ受信した際は、Zustand の State を直接更新して React の再描画をトリガーする。

## 4. スタイリング戦略 (Tailwind CSS)

macOS ネイティブの Spotlight や Raycast のような、洗練されていてプレミアム感のあるデザインを目指す。

- **ダークモード対応**: Tailwind の `dark:` モディファイアを全面的に活用し、OS のカラーテーマに追従させる。
- **グラスモーフィズム**: `backdrop-blur` や半透明の背景色 (`bg-opacity`) を使用して、macOS 特有の透け感（Vibrancy）を表現する。
- **デザインシステム**: Tailwind の `tailwind.config.js` を拡張し、kura 独自の色（洗練されたアクセントカラー等）やモダンなフォント（Inter, SF Pro 等）を定義する。
